# SOC Analysis Portfolio

This repository contains hands-on security investigations completed as part of my cybersecurity training. The cases are based on realistic SOC scenarios involving phishing analysis, firewall alerts, threat intelligence enrichment, and incident investigation.

The goal of this portfolio is to demonstrate my approach to alert triage, evidence collection, analysis, and decision-making in a Security Operations Center (SOC) environment.

## Investigations

### 1. Phishing Analysis (False Positive)

A phishing alert triggered by an onboarding email containing an external URL. Investigation included email analysis, business context validation, and URL reputation analysis to determine whether the communication was legitimate.

**Skills demonstrated:**

* Email analysis
* Alert triage
* Threat intelligence enrichment
* URL reputation analysis
* False positive determination
* Security documentation

### 2. Access to Blacklisted External URL Blocked by Firewall (True Positive)

A firewall alert triggered when a workstation attempted to access a blacklisted URL. Investigation included firewall log analysis, user activity review, and URL reputation analysis to validate the alert and assess potential risk.

**Skills demonstrated:**

* Firewall alert triage
* Network log analysis
* Threat intelligence enrichment
* URL reputation analysis
* True positive determination
* Security documentation

## Investigation Methodology

Each investigation follows the same process:

1. Review the alert and identify key entities.
2. Collect relevant evidence from available data sources.
3. Perform enrichment using threat intelligence and reputation analysis.
4. Analyze findings and determine impact.
5. Classify the alert as a True Positive or False Positive.
6. Document conclusions and recommendations.
